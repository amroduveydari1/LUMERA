# LUMÉRA

A contemporary furniture catalog and digital showroom concept, focused on product presentation, collections, and material storytelling.

**Live preview:** https://lumra-one.vercel.app

## Features
- Product and collection browsing with detail pages
- Materials and editorial journal sections
- Animated page transitions
- Concierge interface and contact experience

## Built with
React, TypeScript, Vite, React Router, Motion, Three.js / React Three Fiber, and Express-related server dependencies.

## Run locally
```bash
npm ci
npm run dev
```

## Structure
`src/pages/` holds product, collection, journal, and contact views. `src/components/` contains shared UI. `api/quote.ts` provides a quote-related API endpoint.

## Status
A digital showroom concept, Quote handling, external integrations, and production configuration should be reviewed before handling real customer information.
