# LUMÉRA

A digital furniture showroom exploring modern design through products, collections, and visual storytelling.

[Live website](https://lumra-one.vercel.app)

### Highlights
- Furniture collections and product pages
- Materials and journal sections
- Smooth page transitions
- Concierge and quote request interfaces

**Stack:** React, TypeScript, Vite, React Router, Motion, Three.js

### Run locally
```bash
npm ci
npm run dev
```
